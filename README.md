# Employee-Raise-issue
A ServiceNow application for raising and managing employee issues through a custom Service Portal

Platform:

ServiceNow

Project type:
    Employee Raise issue
Objectives:

1.To provide employees with an easy way to raise issues.
2.To create a centralized system for managing employee issues.
3.To store issue details in a custom ServiceNow table.
4.To simplify issue submission through a Service Portal.
5.To maintain accurate Category and Subcategory selection.
6.To apply business rules using UI Policies.
7.To automate issue record creation using a Record Producer.
8.To improve issue tracking and management in ServiceNow.

Technologies/ServiceNow Features:

1.ServiceNow Custom Application
2.Custom Tables and Fields
3.UI Policies
4.Dependent Fields
5.Record Producer
6.Service Portal
7.Service Portal Widgets
8.Testing and Validation
